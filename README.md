# BRP-Pecas

<p>O software BRP Peças tem por objetivo implementar um sistema PDV, ou seja, nada mais é que um sistema onde vai facilitar o controle de gastos e estoque de uma loja. Com isso, retendo um  controle de preços, controle de pedidos para o fornecedor, controle sobre seus potenciais clientes e por fim um maior controle sobre todas as vendas que serão efetuadas e tendo no final de cada mês um resumo detalhado de todas as transações que aconteceram.</p>
